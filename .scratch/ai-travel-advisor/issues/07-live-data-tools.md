# 07: Live-data Tools

**Status:** closed

Weather, exchange rates and country facts come from keyless, typed tools, with a status
line while they run and Citations under the reply. REST Countries started requiring a key
during the build, so country facts come from the World Bank (ADR-0003). The rule that tool
results are never instructions sits in the fixed part of the prompt, not the editable
instructions, so a traveler can't delete it.
